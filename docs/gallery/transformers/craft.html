Self-attention, for readers of LSTMs and CNNs After Vaswani et al., 2017 · US 10,452,978 B2

Self-attention lets every token read every other token in one step.

You already know two answers to the question “which inputs does this position get to see?” An LSTM carries a summary forward one step at a time. A convolution looks through a fixed window.

A Transformer computes, for every pair of positions, how much one should read from the other, and then reads them all at once. Below: why that’s different, the formula worked by hand, then the whole machine.

How far is token 1 from token 6? Follow the blue path. Information and gradients both fade along long paths, which is the whole reason the LSTM cell state exists. Attention makes every path length one.

Vaswani et al., “Attention Is All You Need,” NeurIPS 2017, Table 1. n = sequence length, d = width, k = kernel size.
LayerCost per layerSequential stepsLongest path
RecurrentO(n·d2)O(n)O(n)
ConvolutionalO(k·n·d2)O(1)O(logkn)
Self-attentionO(n2·d)O(1)O(1)

The bill for those short paths is the n2 term. Double the context and the attention matrix quadruples. For sentences, where n is smaller than d, that’s cheaper than a recurrent layer. For a book, it isn’t, and most of the work on long-context models since 2017 is about that one term.

The middle column matters more in practice. Zero sequential steps means a GPU can process the whole sequence in one pass during training, with no backprop through time.

FIG. 2

Attention is a soft dictionary lookup, and every token is both the question and the answer

Stack the sequence as rows of a matrix X∈ℝn×dmodel. Project it three ways with learned weights:

Q=XWQ,K=XWK,V=XWV

The query row for a token says what it’s looking for. The key row says what it offers. The value row is what it hands over if chosen. Every token gets all three, so every token asks and every token answers.

Attention(Q,K,V)=softmax(QK⊤dk)V (1)

QK⊤ is an n×n table of dot products, one score per (reader, read) pair. The softmax runs along each row, so each token spends exactly one unit of attention across the sequence. Multiplying by V turns those weights into a weighted average of values. The output has the same shape as the input: one new vector per token, now mixed with context.

Nothing in equation (1) knows about position or distance. Token 1 can pull from token 6 as easily as from token 2, which is FIG. 1’s single hop.

Same weighted sum as a convolution, opposite source of weights

yi=∑j=i−ri+rwj−ixjvs.zi=∑j=1nαijvj

A conv weight depends on the offset j−i and is frozen after training. An attention weight αij depends on what tokens i and j contain, and it’s recomputed for every input. Think of it as a kernel the size of the whole sequence, generated on the fly.

Worked by hand: who does “it” read?

Four tokens, dk=4. The projections are already applied; these are toy numbers chosen so you can check them.

  1. 1

    Queries and keys. One row per token: the, cat, sat, it.

    Q=[0100101011002010]K=[0101201001101001]
  2. 2

    Score every pair. Entry (i, j) is qi·kj. The “it” row scores 5 against “cat”.

    QK⊤=[1010031112110512]
  3. 3

    Scale by 4=2, softmax each row. “It” now puts 0.69 of its attention on “cat”.

  4. 4

    Mix the values. Each row of V has dv=2 here.

    V=[0.10.01.00.20.01.00.30.3]

    The new vector for “it” is 0.06vthe+0.69vcat+0.09vsat+0.15vit = (0.75, 0.28), mostly cat.

Scaling the scores keeps the softmax trainable

If the components of q and k are independent with mean 0 and variance 1, then q·k has variance dk. At dk=64, raw scores spread to about ±8, the softmax goes nearly one-hot, and its gradients vanish. Dividing by dk puts the variance back at 1.

A mask makes it causal, like a forward-only LSTM

softmax(QK⊤dk+M)V Mij={0j≤i−∞j>i

For generating text left to right, future positions get −∞ before the softmax, so their weights are exactly zero. It’s the causal-conv trick, applied to a lookup.

FIG. 3

Eight copies of that lookup, stacked six deep, make the Transformer

  1. 102Input embedding

    Token ids become vectors of width dmodel=512, scaled by dmodel. The output layer (130) reuses this same matrix.

  2. 104Positional encoding

    Shuffle the inputs to equation (1) and its outputs shuffle the same way; it has no sense of order. So order is added in, as fixed sinusoids:

    PE(p,2i)=sin(p/100002i/dmodel)PE(p,2i+1)=cos(p/100002i/dmodel)

    An LSTM got order free from its loop, a conv from its kernel offsets.

  3. 110Multi-head self-attention

    MultiHead=Concat(head1,…,headh)WOheadi=Attention(QWiQ,KWiK,VWiV)

    h=8 heads, each dk=64 wide, for about the cost of one 512-wide head. Treat them like output channels: each learns its own kind of relation, one tracking syntax, another coreference.

  4. 118N × stack

    The encoder repeats 110, 112 and 114 six times, and the decoder repeats its own stack six times. Every layer keeps the sequence length: no pooling, no stride.

  1. 106Outputs, shifted right

    In training, the decoder sees the true target offset by one position, every position at once. That’s teacher forcing without the time loop, and the reason training runs in parallel.

  2. 120Masked self-attention

    The decoder’s lookup over the tokens it has produced so far, with the causal mask M from FIG. 2.

  3. 122Cross-attention

    Queries come from the decoder; keys and values come from the encoder’s final output (blue line). If you’ve bolted Bahdanau attention onto an LSTM seq2seq model, this is that attention, kept, with the LSTMs around it removed.

  4. 112Add & norm

    LayerNorm(x+Sublayer(x))

    Wraps every sublayer, in both towers. The residual is the LSTM cell state’s additive highway, rebuilt between layers, so gradients reach layer 1 intact. LayerNorm normalizes each token across its features, not across the batch.

  5. 114Position-wise feed-forward

    FFN(x)=max(0,xW1+b1)W2+b2

    Also in both towers. 512 → 2048 → 512, applied to each token separately. The paper calls it what you’d call it: two convolutions with kernel size 1. Attention mixes across tokens; this mixes within one.

  6. 130Linear + softmax

    Projects each decoder vector to vocabulary size and turns the scores into next-token probabilities.

N = 6dmodel = 512dff = 2048h = 8dk = dv = 64dropout 0.1params 65M

Since 2017, most models keep one tower

GPT-style models are the right half of FIG. 3 without 122: masked self-attention and feed-forward, stacked. BERT-style models are the left half alone. Most modern stacks also move the LayerNorm in front of each sublayer (“pre-norm”), which trains more stably when the stack gets deep.

The parts list is otherwise the one above. If you can read FIG. 3, you can read the architecture section of nearly any language-model paper.
