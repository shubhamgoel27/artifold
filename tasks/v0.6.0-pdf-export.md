# v0.6.0 — PDF export

**Status:** done (2026-06-02). 35/35 PDF tests + 30/30 v0.5.5 regression all pass.

**Trigger:** "is HTML→PDF export from the UI a nice functionality?"
**Decision:** ship as the "full combo" — PDF endpoint + UI button + `/craft` print-CSS update.

## Why not just Cmd+P

Browsers already save any page as PDF. The artifold export is meaningfully better only because we control the source — every `/craft` artifact now ships with `@media print` rules tuned per design mode, so the print output matches the screen view instead of breaking margins / losing backgrounds / stripping colors.

## What shipped

### Core (`artifold/pdf.py`)
- `export_pdf(html_path, format, landscape, margin, print_backgrounds) → Path`
- Uses Playwright with `emulate_media("print")` so `@media print` rules apply
- networkidle + 1.5s settle = CDN fonts loaded, JS hydrated
- Default output path: `<source-dir>/<stem>.pdf`; falls back to `~/Downloads/<stem>-<sha>.pdf` for read-only source dirs
- Records into provenance: `exports: [{format: "pdf", page_size, landscape, path, size, created_at}]`
- Auto-installs Chromium on first use (shared with shoot via the now-public `shoot.ensure_chromium()`)

### Server (`artifold/serve.py`)
- `POST /export-pdf {path, format, landscape, print_backgrounds, margin}` → `{ok, path, size}`
- `GET /open?p=…` → `subprocess.Popen(["open", path])` on macOS (xdg-open / explorer on Linux/Win)
- `GET /reveal?p=…` → `open -R path` on macOS (reveals in Finder)
- All three reject paths outside configured roots OR `~/Downloads`

### UI (`artifold/template.html`)
- New PDF icon button in the detail header, next to Share / Open
- Click → POST /export-pdf, spinner during render
- Success: action-toast with `Open` and `Finder` buttons (call /open and /reveal)
- Failure: surfaces the server error

### CLI (`artifold/cli.py`)
- `artifold export-pdf <path> [--out FILE] [--format A4|Letter|Legal|...] [--landscape] [--margin 12mm] [--no-backgrounds] [--open]`

### `/craft` SKILL.md (Step 5.5: print-ready CSS)
- Every artifact must include the base `@media print` block (color-adjust:exact, break-inside:avoid sections, hide nav/buttons, expand link URLs)
- Per-mode rules for 15 modes (terminal-tui: invert; data-dashboard: thicker sparklines; field-guide: page-break per route; retro-90s-web: flatten bevels; etc.)
- New self-check item #11: did I include print rules?
