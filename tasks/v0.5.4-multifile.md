**Triggered by:** `frontier-lab-prep` thumb + preview rendered broken (sibling CSS/JS files 404'd).
**Approach:** A (serve siblings) + light B (share-time inlining).

## What breaks today

- `artifold serve` /file?p=/x/y/index.html serves only the HTML. Browser then
  fetches `./styles.css` as `http://localhost:8787/styles.css` → 404 (handler
  routes through cache dir).
- Thumbnails partially work since Playwright under `file://` resolves siblings,
  but `wait_until="load"` + 900ms settle misses JS-heavy renders.
- `artifold share` writes the HTML bytes verbatim to GH Pages, so the shared
  URL is also missing its sibling CSS/JS.

## Plan

### A. Serve siblings (server-side)
- [x] Add `_dir_tokens: dict[str, Path]` registry in `serve.py`
- [x] `/file?p=<abspath>` for HTML responses: register dir → token, inject
  `<base href="/asset/<token>/">` into `<head>` (skip if `<base>` exists)
- [x] New `/asset/<token>/<rel>` route — looks up token, validates `<rel>`
  doesn't escape dir, validates final path is under a configured root, serves
  with mimetype
- [x] Whitelist asset extensions; reject .py .env .sh .key etc.

### Light B. Bundle at share time
- [x] New module `artifold/bundle.py` with `bundle_html(path) -> bytes`
- [x] Inline `<link rel="stylesheet" href="local.css">` → `<style>...</style>`
- [x] Inline `<script src="local.js">` → `<script>...</script>` (drop src)
- [x] Inline `<img src="local.png">` → base64 data URI (cap each at 500 KB)
- [x] Inline `url(local.foo)` inside the inlined CSS
- [x] Skip remote URLs (http/https/data:) — leave as-is
- [x] `share.py` calls `bundle_html(file)` before `write_bytes`

### Shoot (thumbnails)
- [x] Change `wait_until="load"` → `"networkidle"` with 12s timeout fallback
- [x] Bump settle from 900ms → 1500ms for JS hydration

## Out of scope (deferred)

- CDN inlining (Google Fonts → base64 @font-face). Useful for offline
  portability but adds significant size; not needed for the immediate fix.
- True project-aware indexing (treating dirs as artifacts). Bigger product
  change.
- SSR snapshot fallback for dynamic JS apps that don't render statically.
