# v0.10 — Artifold as the substrate, /craft as one option

## What the competitive research found

The design-skill category is crowded and Artifold's category is empty.

| Stars | Project | Output marker | Cross-run memory |
|---|---|---|---|
| 83.3k | Leonxlnx/taste-skill | **none** | **none** |
| 27.7k | Nutlope/hallmark | CSS stamp | `.hallmark/log.json`, per project |
| 23.8k | alchaincyf/huashu-design | **none** | **none** |
| 936 | bitjaru/styleseed | — | `STYLESEED.md`, for consistency not variety |
| 15 | shubhamgoel27/artifold | 9 meta tags | machine-wide library |

I read the full `SKILL.md` of the top three (87 KB, 67 KB, 64 KB). Two of
the three biggest design skills in existence write nothing into their
output and remember nothing between runs. taste-skill has 83k stars and
zero cross-run awareness: its three dials are inferred per run and
discarded.

Meanwhile no tool at all indexes a local corpus of AI-generated HTML. The
nearest analogue is Image MetaHub (318★), which is the same architecture
for Stable Diffusion images.

So: /craft competes with an 83k-star incumbent. Artifold competes with
nobody, and the thing Artifold does — remember what you made, across
projects — is exactly what the incumbents do not do.

## The move

Stop shipping Artifold as "the app that goes with /craft". Ship it as the
library any design skill can write into.

Three parts:

1. **A contract.** The nine `artifold:*` meta tags become a documented,
   vendor-neutral spec that any skill can emit in four lines of HTML.
2. **Adapters.** For skills that already stamp their own output, read
   their format directly. Hallmark is the only one of the big three that
   does, and it is worth the work: a CSS stamp plus `.hallmark/log.json`.
3. **Positioning.** README, `artifold init` and a new `artifold skills`
   command present /craft as one option beside Hallmark, taste-skill and
   huashu-design — with an honest table of what Artifold recovers from each.

## What already works with no cooperation

`design.py` is pure regex over any HTML and its docstring already commits
to being generator-neutral. On output from any skill Artifold already gets
palette, fonts, CSS tokens, gradient/glass/animation flags, and a DOM
skeleton hash — plus thumbnails, categories, full-text search, versions,
revisions, opens, sharing and PDF export.

What is lost without tags: `intent`, `conceit`, and the four rotation
axes. That is cmd-K search quality, the design facets, and the loop.

## Honest risk

119 of the user's 134 artifacts carry metadata *because* /craft wrote it.
Demoting /craft in the pitch must not demote it in the box: it stays
bundled, and it remains the reference implementation of a skill that
instruments its own output.

Hallmark ships fast (138 commits). The adapter will drift. It is written
to fail soft: a stamp that no longer parses yields no metadata, never an
error.

The vocabularies do not map cleanly. A macrostructure is not a layout
archetype and a theme is not a design mode. The mapping is lossy, so the
raw foreign values are kept alongside the mapped ones.
